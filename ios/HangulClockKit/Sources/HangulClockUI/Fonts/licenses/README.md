# 글꼴 사용권

이 폴더의 HC*.ttf 는 아래 글꼴에서 판 글자 30자만 남기고 이름을 바꾼 것이다(tools/subset_fonts.py).
SIL Open Font License 1.1 을 따른다. 예약 이름(Source, Plex)을 쓰지 않으려고 이름을 바꿨다.

- HCSans-Light, HCSans-Medium: Noto Sans KR (NotoSansKR-OFL.txt)
- HCSerif-Regular: Noto Serif KR (NotoSerifKR-OFL.txt)
- HCGrotesk-Medium: IBM Plex Sans KR (IBMPlexSansKR-OFL.txt)
